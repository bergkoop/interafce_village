# The Rusty Tankard

A fantasy tavern district for NeoCity. Pick up quests from the quest board and listen to the bard.

## How to run

Open `index.html` with Live Server in VS Code. Opening the file by double-clicking won't work, because browsers block `import` from local files.

## Animations

The camera moves smoothly through the tavern, but only when animations are turned on in your operating system. If "reduce motion" is on, the camera jumps straight to each spot instead. This is on purpose: the site respects that setting for people who get dizzy from moving screens.

To see the animations:

- **Windows 11:** Settings > Accessibility > Visual effects > turn on Animation effects
- **Windows 10:** Settings > Ease of Access > Display > turn on Show animations in Windows
- **macOS:** System Settings > Accessibility > Display > turn off Reduce motion
